## 📖 Sobre

Este repositório reúne os códigos que escrevo enquanto aprendo programação: exercícios do **CS50** (Harvard), os projetos das aulas dos cursos da **DiscoverOn** e do **DevClub**, projetos orientados por mentoria e criações pessoais.

Os projetos são organizados por origem, para facilitar a navegação e acompanhar minha evolução ao longo do tempo. Alguns ainda estão incompletos, e isso faz parte do processo de aprendizado.

## 🗂️ Estrutura

```
Codigos-Testes/
├── CS50/                    # Exercícios e problem sets do CS50
├── Projetos-DiscoverOn/     # Projetos das aulas do curso da DiscoverOn
├── Projetos-Meu/            # Projetos pessoais e experimentos
├── Projetos-Rodolfo Mori/   # Projetos desenvolvidos com Rodolfo Mori
└── .gitignore               # Arquivos que o Git deve ignorar
```

| Pasta | O que tem |
|---|---|
| 📘 **CS50** | Resoluções dos exercícios do curso de ciência da computação de Harvard |
| 🚀 **Projetos-DiscoverOn** | Projetos propostos nas aulas do curso da DiscoverOn |
| 💡 **Projetos-Meu** | Projetos autorais, testes e ideias que desenvolvi por conta própria |
| 🎓 **Projetos-Rodolfo Mori** | Projetos desenvolvidos durante as aulas/mentoria com Rodolfo Mori |

## ▶️ Como usar

Para ver qualquer projeto no seu computador:

```bash
# 1. Clone o repositório
git clone https://github.com/dvi-souzz/Codigos-Testes.git

# 2. Entre na pasta do projeto desejado
cd Codigos-Testes/Projetos-Meu
```

- **Projetos web (HTML, CSS e JavaScript):** abra o arquivo `index.html` no navegador.
- **Projetos em Python:** execute com `python nome_do_arquivo.py`.
